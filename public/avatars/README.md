# Team Avatars

This directory should contain the following avatar images for team selection:

## Required Images:
- `horse.png` - حصان (Horse)
- `lion.png` - أسد (Lion) 
- `eagle.png` - نسر (Eagle)
- `wolf.png` - ذئب (Wolf)
- `bear.png` - دب (Bear)
- `tiger.png` - نمر (Tiger)
- `falcon.png` - صقر (Falcon)
- `panther.png` - فهد (Panther)

## Image Requirements:
- **Format**: PNG with transparent background
- **Size**: 512x512 pixels (or larger square format)
- **Style**: Cartoon/illustrated style similar to the horse image shown in the design
- **Background**: Transparent or white circle background

## Usage:
These images are used in the team setup page where users can:
1. Navigate through avatars using left/right arrows
2. Select an avatar for each team
3. See a preview of selected avatar with team name

## Fallback:
If images are not found, the component will gracefully fall back to the first available image.
